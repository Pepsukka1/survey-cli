# survey-cli

Run surveys from your terminal. Agent-friendly, type-safe, OSS.

```bash
bunx survey-cli take onboarding
```

## Quickstart

Install dependencies with Bun, then see `examples/` for survey definitions and usage.

## Status

V1 MVP — local-first, no backend, no cloud. See shaping.md for roadmap.
